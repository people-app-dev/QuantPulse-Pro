# QPP App 设计文档

## 概述

QPP 是一款面向大众的个人理财工具，帮助普通用户通过风险评估和资产配置建议进行理性投资，同时提供轻量社区供用户交流理财经验。

- **平台**：微信小程序
- **后端**：微信云开发（云数据库 + 云存储 + 云函数）
- **目标用户**：所有有理财需求的普通人（不区分新手/老手）
- **开发者背景**：零基础，边学边做

---

## 一、MVP 功能范围

### 1.1 风险评估（问卷测评）

- 10 道选择题，覆盖 4 个维度：风险承受能力、投资知识储备、流动性需求、投资期限偏好
- 用户随时可重测，不限制次数
- 完成测评后生成：投资者类型（保守/稳健/进取）、风险评分（0-100）、建议资产配置比例
- 测评问题由金融专硕背景的产品 owner 设计

### 1.2 资产配置

- 基于测评结果展示建议配置方案（货币基金/指数基金/债券基金/现金储备 的比例）
- 可视化进度条展示各项占比
- 预期年化波动区间展示
- 配置饼图图标随用户实际投资组合动态变化（个性化）

### 1.3 社区

- 图文动态发布（小红书式轻量分享：图片 + 短文 + 话题标签）
- 信息流首页（按时间/热度排序）
- 点赞、评论基础互动
- 话题标签分类（#理财故事 #每日打卡 #新手问答 #晒收益 #读书笔记）
- 内容安全审核（微信内容安全 API + 敏感词过滤）

### 1.4 用户系统

- 微信一键授权登录
- 个人主页（动态、测评记录、收藏）
- 个人信息管理

## 二、技术架构

```
┌─────────────────────────────────┐
│         微信小程序前端            │
│   WXML + WXSS + JavaScript      │
│                                 │
│  ┌──────────┐  ┌──────────┐    │
│  │ 首页      │  │ 测评      │    │
│  │ 社区      │  │ 我的      │    │
│  └──────────┘  └──────────┘    │
└──────────────┬──────────────────┘
               │ 微信 API
┌──────────────▼──────────────────┐
│       微信云开发（后端）          │
│                                 │
│  云数据库     云存储     云函数   │
│  (用户/测评   (图片/    (测评计算 │
│   结果/帖子)   文件)     内容审核) │
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│         外部服务                 │
│  微信登录 · 内容安全API          │
└─────────────────────────────────┘
```

### 技术选型理由

- **微信小程序**：中国市场用户获取成本最低，微信生态内一键登录/分享，审核和支付体系成熟
- **微信云开发**：免运维，天然集成小程序，自动扩缩容，适合个人开发者
- **不选 React Native/Flutter**：学习曲线陡，Firebase/Supabase 在中国大陆不稳定

## 三、设计系统

### 3.1 色彩

| 用途     | 色值       | 说明         |
| -------- | ---------- | ------------ |
| 主色调   | `#007AFF`  | iOS 蓝，信任 |
| 主色深   | `#0056CC`  | 按压态       |
| 背景灰   | `#F2F2F7`  | 页面背景     |
| 卡片白   | `#FFFFFF`  | 卡片/内容区  |
| 文字黑   | `#000000`  | 主标题       |
| 文字深灰 | `#3C3C43`  | 正文         |
| 文字浅灰 | `#8E8E93`  | 辅助说明     |
| 分割线   | `#E5E5EA`  | 边框/分割    |
| 成功绿   | `#34C759`  | 正向数据     |

### 3.2 字体

- 系统默认字体（iOS SF Pro / Android 系统字体）
- 标题：较大字号 + 负字间距（-0.5px）
- 正文：标准行高 1.4-1.5
- 辅助文字：较小字号 + 灰色

### 3.3 圆角与间距

- 页面卡片圆角：12px - 16px
- 按钮/输入框圆角：10px
- 小标签圆角：8px
- 统一间距节奏：8px / 12px / 16px / 20px

### 3.4 图标系统

SF Symbols 风格 SVG 线条图标，统一 1.5px 描边，24×24 viewBox。选中态填充，未选中态描边。

| 图标   | 语义         | 选中态 | 未选中态     |
| ------ | ------------ | ------ | ------------ |
| 首页   | 房子轮廓     | 填充蓝 | 描边灰       |
| 测评   | 高低柱状条   | 填充蓝 | 描边灰       |
| 配置   | 饼图分段     | 填充蓝 | 描边灰       |
| 社区   | 同心圆十字   | 填充蓝 | 描边灰       |
| 我的   | 人物剪影     | 填充蓝 | 描边灰       |

资产配置图标特殊行为：根据用户实际投资组合比例动态渲染饼图分段大小。

## 四、页面结构

### 4.1 底部导航（Tab Bar）

| Tab    | 页面路径    | 图标     |
| ------ | ----------- | -------- |
| 首页   | pages/index | 房子     |
| 测评   | pages/quiz  | 柱状图   |
| 社区   | pages/feed  | 同心圆   |
| 我的   | pages/mine  | 人物剪影 |

### 4.2 首页（pages/index）

- 顶部：大标题「理财」+ 今日市场概览（上证指数等）
- 市场数据卡片：指数名称、当前点位、涨跌幅
- 两个功能入口卡片：风险评估 → 资产配置
- 社区动态精简流（最新 3 条）

### 4.3 测评页（pages/quiz）

- 顶部：题号进度（第 X/10 题）+ 进度条
- 中间：题目 + 4 个选项
- 底部：上一题 / 下一题 导航
- 右侧/底部：测评维度说明（4 个维度）
- 完成页：类型判定 + 风险评分 + 建议配置 + 下一步行动
- 支持随时重测（完成页提供「重新测评」按钮）

### 4.4 社区页（pages/feed）

- 顶部：话题标签横向滚动
- 信息流：用户动态卡片（头像、昵称、时间、正文、互动数据）
- 发布入口：底部悬浮按钮或导航栏按钮
- 发布页：图片上传（最多9张）+ 正文输入 + 话题标签选择

### 4.5 我的页（pages/mine）

- 头像 + 昵称 + 投资者类型标签
- 功能列表：我的动态、测评记录、我的收藏、设置

## 五、数据模型

### 5.1 用户（users）

```
_id: string (openid)
nickname: string
avatar: string
investorType: string (保守型/稳健型/进取型)
riskScore: number (0-100)
createdAt: datetime
```

### 5.2 测评记录（assessments）

```
_id: string
userId: string

dimensions: object (四个维度得分)
riskScore: number
investorType: string
allocation: object (配置比例)
createdAt: datetime
```

### 5.3 动态帖子（posts）

```
_id: string
userId: string
content: string
images: array (云存储 fileID)
tags: array (话题标签)
likes: number
comments: number
createdAt: datetime
```

### 5.4 评论（comments）

```
_id: string
postId: string
userId: string
content: string
createdAt: datetime
```

## 六、关键交互规则

1. **测评可重测**：用户随时进入测评页重新作答，历史记录保留在「我的 → 测评记录」中
2. **资产配置图标动态化**：当用户更新投资组合后，配置图标中的饼图分段比例随之变化
3. **内容审核**：发布动态时调用微信 `security.msgSecCheck` 进行内容安全检测
4. **登录**：使用 `wx.login` + 云函数获取 openid，静默登录无感知

## 八、开发者学习路径

作为零基础开发者，建议按以下顺序学习：

1. **HTML + CSS 基础**（2 周）— 理解页面结构和样式
2. **JavaScript 基础**（4 周）— 变量、函数、数组、对象、异步
3. **微信小程序官方教程**（3 周）— WXML/WXSS/JS，跟着官方 Demo 做
4. **微信云开发文档**（2 周）— 云数据库 CRUD、云函数
5. **开始开发 MVP**（边学边做）

预计从零到 MVP 上线：**4-6 个月**（每天投入 2-3 小时）
